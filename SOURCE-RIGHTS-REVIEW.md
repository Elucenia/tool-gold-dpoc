# Source and material scope: gold-dpoc

## Current distribution scope

Independent ELUCENIA numerical classification code with a previously assessed mMRC grade input (0–4). The interface, ten-language documentation and embedded browser contract contain only numeric grade options; the five modified/translated mMRC descriptors have been removed. The package does not administer a questionnaire or offer an official scale translation. CAT/CAAT is likewise a numeric score input, with no CAT questions.

## Source evidence and limits

[UKRI/MRC](https://www.ukri.org/councils/mrc/facilities-and-resources/find-an-mrc-facility-or-resource/mrc-dyspnoea-scale/) permits use of its original scale with attribution and changes identified, but explicitly cannot authorize modified scales or translations. That original-scale grant is not claimed for this presentation. The original instrument should be assessed separately using an appropriate authorized version.

[GOLD legal policy](https://goldcopd.org/legal-policy/) reserves rights in its website material. This independent implementation cites the scientific method and contains no GOLD report PDF, report image, logo or official calculator code. The code licences and attribution notices are preserved in their existing scopes. No whole-instrument, clinical, professional translation or unrestricted mixed-material rights approval is asserted.

The earlier directed rights audit described the previous worded interface. It remains historical evidence; the current numeric-only presentation and test bindings are recorded in GOLD-PRIOR-GRADE-PRESENTATION.json.
